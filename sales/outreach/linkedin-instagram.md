# LinkedIn / Instagram outreach

## LinkedIn (connection note, <300 characters)

> Hi [Name] — I work with Digital Fuzed. We make [salon / school / restaurant] software that’s already live. If you ever want a 15-min demo of the actual product (not a pitch deck), happy to show it.

## LinkedIn (after they accept)

> Thanks for connecting. Curious: what do you use today for [fees / POS / appointments / leads]? If it’s Excel or a tool you’re fighting, I can show ours on a screen share this week. CTA is simple — book a free demo or ask for pricing.

## LinkedIn (comment, not DM spam)

Comment on their post only if you have something true to add. Then DM. Do not comment “Great insights!” and pitch.

## Instagram DM (salon, restaurant, realtor)

> Hi, I saw [Business] on Instagram. We built software for [salons] to run bookings, billing and stock. If you want, I can show the live app — 15 minutes. WhatsApp +91 8459148396.

Keep it one message. If no reply in 5 days, one bump. Then stop.

## Prospecting sources (daily mix)

| Source | Best for |
| --- | --- |
| Google Maps | Restaurants, salons, clinics, shops |
| Instagram | Salons, restaurants, brokers |
| LinkedIn | School admins, hospital admins, business owners |
| Directories / Justdial-style lists | Volume, lower quality — qualify harder |
| Referrals | Highest quality — ask every won/lost polite contact |

Put **Lead Source** on every row.
