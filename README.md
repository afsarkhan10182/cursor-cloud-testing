# Digital Fuzed — Product Market Validation Kit

Stop measuring progress by how much software we build.

Measure:

**Prospects → Conversations → Qualified Leads → Demos → Proposals → Customers → Revenue → Retention**

This repository is the operating system for the first 30–90 days of sales and marketing. It does not add new products. It turns the existing products into a test that answers: *who buys, what they buy, why they buy, what stops them, and which channel works.*

## Two tracks, one month

| Track A — Outbound | Track B — Content / inbound |
| --- | --- |
| One salesperson finds, contacts, qualifies, books demos, follows up | Founders record real software demos, cut shorts, publish |
| Every lead lives in the master tracker | Every video lives in the content tracker |
| CTA: **Book a free demo** | CTA: **Book a free demo / Contact us for pricing** |

Do not pick a winning product yet. Compare products at month-end using [docs/08-month-end-decision.md](docs/08-month-end-decision.md).
