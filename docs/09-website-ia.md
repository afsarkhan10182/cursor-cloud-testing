# Website structure (product pages, not “we build everything”)

The current homepage lists many industries at once. That is useful internally. Publicly it can sound like a custom shop with no focus.

**Do not present Digital Fuzed only as “we make every kind of software.”**

Create a dedicated page per product we are testing:

| URL | Product |
| --- | --- |
| digitalfuzed.com/salon | Salon |
| digitalfuzed.com/restaurant | Restaurant |
| digitalfuzed.com/school-erp | School ERP |
| digitalfuzed.com/hospital | Hospital |
| digitalfuzed.com/inventory | Inventory |
| digitalfuzed.com/textile | Textile |
| digitalfuzed.com/real-estate | Real estate |

Static HTML drafts live in [`website/`](../website/). They follow the same story on every page:

**Problem → Software → Key features → Screenshots / video → Demo → Pricing / contact CTA**

Single CTA on every page:

**Book a free demo / Contact us for pricing**

WhatsApp: +91 8459148396  
Email: info@digitalfuzed.com

## Homepage change (later, after a winner)

Keep a short company homepage. Link tiles to product pages. Do not dump every module on the first screen.

Until a winner is known, product pages can go live even if the homepage stays as-is.

## Trust cleanup (founders)

The live site currently uses generic team names and stock-style proof. Owners will Google us. Before serious outbound:

- [ ] Real founder names and photos, or no team section
- [ ] Real testimonials or remove them
- [ ] Align claims (“no upfront payment”, “200+ businesses”) with reality
- [ ] Put a working demo video or screenshots on each product page
- [ ] Make inventory.digitalfuzed.com a real demo or take the link down

A salesperson cannot outrun a website that looks invented.
