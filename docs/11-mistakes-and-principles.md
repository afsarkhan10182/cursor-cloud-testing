# Mistakes to avoid

- Hiring multiple salespeople immediately
- Hiring an expensive marketing agency before we know the customer
- Running paid ads before validating messaging
- Building more products instead of selling existing ones
- Excessive custom development for every prospect
- Tracking only calls instead of conversions
- Measuring content only through views / followers
- Selling too cheaply simply to get customers
- Allowing leads to disappear without follow-up
- Assuming most inquiries = best business, ignoring revenue and support burden
- Rewarding the salesperson for raw lead count
- Picking a “main product” from founder preference instead of pipeline data
- Quoting from memory instead of the tracker
- Letting inventory / salon / textile outbound run before a demo exists
