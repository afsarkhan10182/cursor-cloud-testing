# Pricing hypotheses

These are **starting ranges for founder approval**, not a public price list. The salesperson must not invent discounts. If a prospect asks for a number before a demo, share the *range* and book the demo.

Currency: INR. Market: Indian SMEs, starting from Mumbai / nearby.

## Commercial options (offer all, record which they pick)

| Code | Model | When to use |
| --- | --- | --- |
| M | Monthly SaaS | Default for small businesses that want low commitment |
| A | Annual SaaS | Default if they want a better rate; typically ~10 months billed |
| S | Setup + subscription | When onboarding, data import, or training is real work |
| O | One-time license / own server | Only if they insist; price must cover support risk |
| W | White-label / own branding | Only above a minimum deal size |

## What is included (default)

- Software access for agreed users
- Founder-led onboarding call
- Staff training (remote)
- 6 months support on SaaS plans (already claimed on the website — honour it or change the website)
- GST extra

## What is not included (unless quoted)

- Custom features built for one customer
- On-site installation travel
- Hardware (POS printer, biometric, SMS credits, payment gateway charges)
- Data migration from messy Excel beyond a reasonable import
- White-label / own domain unless option O or W

## Discount rules

- Salesperson cannot go below the bottom of the range without a founder.
- Never discount to “just get a logo.” Cheap customers still need support.
- Prefer a smaller package over a reckless discount.
- Record every quoted amount in the lead tracker.

## How to talk about price

> We work with monthly or annual plans, and we can also install on your own server if that is important. After a short demo we will quote against your actual workflow — not a generic package.

If they only want one-time:

> Possible. Own-server and one-time licenses cost more because support and updates still have to be paid for somehow. We will quote both options so you can compare.
