# Pipeline, qualification, and lost reasons

## Pipeline stages (use only these)

**New Lead → Contacted → Replied → Qualified → Demo Booked → Demo Completed → Proposal → Negotiation → Won / Lost**

| Stage | Meaning | Next action required |
| --- | --- | --- |
| New Lead | In tracker, not yet contacted | First contact |
| Contacted | We reached out; no reply yet | Follow up on Next Follow-Up date |
| Replied | They responded in any channel | Qualify |
| Qualified | Passed the checklist below | Book demo |
| Demo Booked | Date/time agreed | Send reminder, prepare demo |
| Demo Completed | Demo happened | Recap + proposal or next demo |
| Proposal | Quote sent | Follow up, handle objections |
| Negotiation | Price / terms / scope in discussion | Founder involved |
| Won | Paid or signed | Onboard |
| Lost | Dead for now | Lost reason required |

Do not skip stages. A WhatsApp “ok send details” is Replied, not Qualified.

## Qualification checklist

A lead is **Qualified** only if all of the following are true:

1. Real business that matches a product we can demo.
2. We spoke to an owner, partner, principal, or clearly identified influencer.
3. They have a current process (manual, Excel, WhatsApp, or other software) and at least one pain.
4. They are open to a demo in the next 14 days **or** have a dated reason to wait (then status stays Replied / follow-up later — not Qualified).
5. Not a student, job seeker, competitor, or vendor fishing for features.

Nice-to-have (record if known, do not block qualification):

- Current software name
- Budget range
- SaaS vs own-server preference
- Who else must approve
- Timeline (this month / this term / next financial year)

## Daily workflow

1. **Prospect research** — Google, Google Maps, LinkedIn, Instagram, directories, networks, referrals, local communities, AI-assisted lists.
2. **Add lead** — every prospect goes in the tracker *before* or immediately after first contact. Never only in personal WhatsApp.
3. **First contact** — phone, WhatsApp, email, LinkedIn, or Instagram. Use the templates in `sales/outreach/`.
4. **Qualify** — checklist above.
5. **Demo** — book, demonstrate the relevant workflow, note requirements.
6. **Follow-up** — every open lead has a **Next Follow-Up** date. No date = the lead is already lost.
7. **Proposal** — only serious opportunities.
8. **Close / Lost** — record outcome and reason.

## Lost reasons (required on Lost)

Use one primary reason:

| Code | Reason |
| --- | --- |
| PRICE | Too expensive |
| COMPETITOR | Already using competitor |
| FEATURE | Missing feature |
| BUDGET | No budget |
| AUTHORITY | Not decision maker |
| INTEREST | Not interested |
| ONETIME | Wants one-time purchase only (and we could not agree) |
| ONSERVER | Wants own server/domain (and we could not agree) |
| CUSTOM | Needs customization we will not do |
| LATER | Follow-up later (use this only with a date; otherwise it is INTEREST) |
| TRUST | Trust issue |
| NORESPONSE | No response after agreed follow-up sequence |
| SUPPORT | Worried about support / founder time |
| OTHER | Other (explain in Notes) |

After 50–100 conversations these reasons are product/market data, not salesperson excuses.

## Activity vs pipeline

Calls, WhatsApp, and emails belong in the **daily activity tracker**.

Money and stages belong in the **master lead tracker**.

Do not judge the month by call count.
