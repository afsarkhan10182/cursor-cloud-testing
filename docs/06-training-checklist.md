# Training checklist (first 7 days)

The salesperson does not need to become a developer. They need to tell the truth, run a simple demo, and know when to pull in a founder.

## Day 0 — Access

- [ ] Google Sheet trackers (edit access)
- [ ] Company WhatsApp number / Business app (not their personal number as the only record)
- [ ] Email (info@ or a sales@ alias)
- [ ] Demo logins for every product that is in outbound this week
- [ ] Price floor sheet ([02-pricing.md](02-pricing.md))
- [ ] This repository / PDF pack of one-pagers
- [ ] Calendar for demos (Google Calendar shared with founders)

## Day 1 — Products (2 hours with a founder)

For each product in the week-1 set:

- [ ] What problem it solves in one sentence
- [ ] Who we call
- [ ] The 4 screens that matter in a demo
- [ ] What we will **not** promise
- [ ] Live URL

Homework: salesperson writes one WhatsApp opener per product in their own words. Founder edits.

## Day 2 — Tools and tracker

- [ ] Add 10 real leads (even if not contacted yet)
- [ ] Practice status changes
- [ ] Practice Next Follow-Up
- [ ] Practice lost reason
- [ ] Watch founder run one 10-minute demo

## Day 3 — Outreach

- [ ] 5 live calls with founder listening (or recordings)
- [ ] Correction on talk-to-listen ratio (they should listen more)
- [ ] No scripts read robotically — use the script as a spine

## Day 4 — Qualification and objections

Role-play:

- “We already use Excel”
- “Send a PDF”
- “Too costly”
- “Put it on our server”
- “Build this extra feature and then we’ll buy”

Correct answer to custom features: *note it, do not promise, founder decides.*

## Day 5 — First unsupervised block

- [ ] Morning research + data entry
- [ ] Afternoon outreach
- [ ] End-of-day: activity row filled, pipeline updated, 3 lines of “what I learned”

## Day 6–7 — Demos

- [ ] Salesperson runs a demo for a founder pretending to be a customer
- [ ] If pass: they may run first live demos with founder on standby
- [ ] If fail: founder runs demos until pass; salesperson still books and qualifies

## Standing rules

- Tracker before sleep. No exceptions.
- Never quote below floor.
- Never leave a lead without a next date if status is not Won/Lost.
- WhatsApp voice notes from owners are gold — summarize in Notes.
- If asked a technical question you don’t know: “I’ll confirm with the product team and get back today.” Then actually get back.
