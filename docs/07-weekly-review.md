# Weekly review (founders + salesperson)

**When:** same slot every week, 30–45 minutes.  
**Input:** master lead tracker + daily activity tracker + content tracker.  
**Output:** written changes for next week (not vibes).

## Agenda

1. Activity last 7 days (5 min)  
   Leads found, calls, WhatsApp, email, LinkedIn, responses.
2. Pipeline (10 min)  
   How many in each stage? What moved? What is stuck?
3. Product split (5 min)  
   Which product got interest, demos, proposals?
4. Message and channel (5 min)  
   Which opener got replies? Which channel actually worked?
5. Lost reasons and feature requests (5 min)  
   Patterns, not anecdotes.
6. Content (5 min)  
   What published? Any enquiries from content?
7. Next week changes (5 min)  
   One targeting change, one message change, one process change. Maximum three.

## Questions (ask every week)

- How many prospects contacted?
- How many responded?
- Which product received most interest?
- Which message generated responses?
- Which channel worked?
- How many demos?
- Why did people reject?
- What features did prospects repeatedly ask for?
- Was price objection common?
- Which competitors were mentioned?
- What should change next week?

## How we judge the salesperson in month 1

Not only sales.

Also:

- Tracker hygiene (every lead has status + next date)
- Qualification quality (founder spot-check)
- Follow-up discipline
- Honesty about what is not working

## Red flags

- Hundreds of leads, almost no conversations
- All leads in “Contacted” forever
- Demos booked with people who cannot buy
- Feature promises made on WhatsApp
- Content published with no CTA

## Green flags

- Notes that sound like a real business
- Lost reasons filled in
- A few serious threads even if not closed
- Clear “this product is dead / this channel is dead” recommendations
